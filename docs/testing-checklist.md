# 테스트 체크리스트

최종 수정일: 2026-05-19

## 실행 전 확인

```text
1. MariaDB 서비스가 실행 중인지 확인한다.
2. backend/.env에 DB 접속 정보와 KAKAO_REST_API_KEY가 설정되어 있는지 확인한다.
3. frontend/.env에 VITE_API_BASE_URL과 VITE_KAKAO_JAVASCRIPT_KEY가 설정되어 있는지 확인한다.
4. Kakao Developers JavaScript SDK 도메인에 http://localhost:5173, http://127.0.0.1:5173이 등록되어 있는지 확인한다.
```

## 실행 명령어

```bash
npm run start:backend
npm run dev:frontend
```

프론트 접속 주소:

```text
http://localhost:5173/consumer
```

## 소비자 화면

```text
[ ] /consumer 접속 시 검색창이 비어 있다.
[ ] 첫 화면에서 기본 기준 위치 주변 매장이 표시된다.
[ ] 카카오맵이 빈 화면이 아니라 실제 지도로 렌더링된다.
[ ] 매장 카드를 클릭하면 지도 마커/팝업이 해당 매장으로 이동한다.
[ ] 지도 팝업이 바로 사라지지 않고 매장/상품/예약 가능 재고를 확인할 수 있다.
```

## 위치 + 상품 검색

```text
[ ] "부평역 주변 버터떡" 검색 시 부평역 기준 주변 버터떡 매장이 표시된다.
[ ] "송도 주변 버터떡" 검색 시 송도 기준으로 지도 중심이 이동한다.
[ ] 송도 주변 반경 5km 안에 매장이 없으면 "예약 가능한 매장이 없습니다" 상태가 표시된다.
[ ] "인하대학교 후문 맛집" 검색 시 카카오 Local REST API로 장소 좌표가 잡히고, 전체 매장 12개가 반환되지 않는다.
[ ] 장소 검색 결과는 location_cache에 저장되어 다음 검색부터 재사용된다.
```

## 상품명 단독 검색

```text
[ ] "버터떡"처럼 상품명만 검색하면 현재 기준 위치 좌표를 기준으로 주변 매장을 조회한다.
[ ] "내 위치" 버튼을 누른 뒤 상품명만 검색하면 브라우저 위치 기준으로 조회한다.
[ ] PC 위치가 부정확할 수 있으므로 발표 시에는 장소명 기반 검색을 주 흐름으로 사용한다.
```

## 예약 흐름

```text
[ ] 매장 카드 또는 지도 팝업에서 예약 화면으로 이동한다.
[ ] 예약 화면에서 매장명, 상품명, 예약 가능 재고가 DB 값과 맞게 표시된다.
[ ] 예약 생성 시 reservable_stock 범위 안에서만 예약된다.
[ ] 예약 성공 후 내 예약 페이지에서 예약 내역이 표시된다.
[ ] 재고 부족 상황에서는 예약 실패 메시지가 표시된다.
```

## 내 예약

```text
[ ] /consumer/reservations 접속 시 API 요청에 실패하지 않는다.
[ ] DB에 저장된 사용자 예약 내역이 표시된다.
[ ] 예약 내역이 없으면 빈 상태 메시지가 표시된다.
```

## 발표 시연 추천 순서

```text
1. /consumer 첫 화면에서 검색창이 비어 있고 지도 중심이 기본 위치인 것을 보여준다.
2. "부평역 주변 버터떡"으로 장소 + 상품 검색을 보여준다.
3. "송도 주변 버터떡"으로 장소 좌표는 잡히지만 주변 매장이 없을 수 있음을 보여준다.
4. "버터떡"으로 현재 기준 위치 기반 상품 검색을 보여준다.
5. 매장 선택 후 예약 화면으로 이동해 재고 기반 예약 흐름을 설명한다.
6. 내 예약 페이지에서 예약 내역 조회 흐름을 보여준다.
```
