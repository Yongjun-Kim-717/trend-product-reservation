# Requirements Summary

## 프로젝트 목적

사용자 위치 기반으로 주변 매장의 유행 상품을 탐색하고, 상품 재고 확인 및 예약을 제공하는 플랫폼을 개발한다.

## 주요 기능

- 사용자는 상품을 검색할 수 있다.
- 사용자는 Kakao Map 기반으로 주변 매장을 확인할 수 있다.
- 사용자는 매장별 상품 재고를 조회하고 예약할 수 있다.
- 예약 시 `reservable_stock`이 감소하고 `reserved_stock`이 증가한다.
- 매장 관리자는 상품 재고를 수정할 수 있다.
- 시스템 관리자는 기준 키워드와 연관 검색어를 관리할 수 있다.
- 매핑 실패 검색어는 `unmapped_searches`에 저장된다.

## 재고 정책

- `total_stock`: 실제 매장 보유 재고
- `reservable_stock`: 온라인 예약 가능 재고
- `reserved_stock`: 이미 예약된 재고

예약은 `reservable_stock` 범위 안에서만 가능하며, 동시 예약 문제를 막기 위해 트랜잭션과 행 잠금을 사용한다.
